# 稳定币与黄金监控

在导航的 **策略 → 稳定币与黄金监控** 打开页面，也可直接访问 `/strategies/asset-monitor`。这是只读观察页面，没有自动开仓功能；白银、石油暂不进入正式页面。

## 使用稳定币交易对列表

- 列表默认只看 USDT、USDC 支付方向；可切换为“全市场观察”查看其他稳定币支付的方向。全市场中的非可用支付币仅作中性观察，不标红、不累计提醒。可按交易所、币种及可提醒折价筛选。
- 正向买入取卖一价；反向买入取原交易对买一价的倒数。反向容量也换算到实际支付币，不能直接沿用原报价金额。
- 买入价严格低于默认 `0.99`，且支付币属于提醒设置中的 USDT／USDC、当前价第一档可买金额达到默认 `100` 个支付币，才标红、累计并提醒。金额门槛可在提醒设置中调整；这是第一档金额筛选，不保证更大金额可成交，也不读取账户真实余额。其余相对价差保持中性观察。
- **市值 / 24h成交额**：展示买入币的全市场流通市值与近24小时成交额（USD），数据源为 CoinGecko `coins/markets`，不代表该交易所或该交易对成交额。反向行按实际买入币查询。复用市值缓存逻辑，每10分钟更新，失败退避1分钟；缺失、同名身份不明确或超过30分钟的数据显示“—”。支持已有 `COINGECKO_DEMO_API_KEY`，429限流时显示来源异常，不影响盘口采集。
- **买到 0.998 的深度**：累计买入价不超过 0.998（含边界）的挂单，以支付币显示累计金额，悬浮显示可买数量及档数。正向累加卖盘价格×数量，反向在原买盘价格×0.998≥1时累加基础币数量。不是平均成交价达到0.998，不含手续费。Gate、Binance、OKX、Kraken取100档，Bybit取50档，Hyperliquid取最多20档；若用满档位仍未越过限价，显示“≥”及“已取深度下限”。行情过期或深度无效显示“—”，有效盘口没有符合限价的档位显示0。
- 相对折价可能来自买入币便宜，也可能来自支付币贵；本页面不判定具体哪枚币偏离美元。
- 列表筛选仅影响查看；后台提醒的可用支付币、第一档金额门槛和双向开关需在“提醒设置”里保存。旧版“全部美元稳定币”提醒设置读取时迁移为 USDT + USDC。

在提醒设置中启用 Bark，复用已有 `BARK_DEVICE_KEY` 和可选 `BARK_SERVER_URL`，配置方法见 [Bark 通知](bark-notification.md)。默认只记录异常，不推送。符合支付币及金额门槛后连续达标默认 30 秒产生事件；金额不足会中断累计，同一事件不重复通知。回升至阈值加 `0.001` 并保持 30 秒后重新布防。报价失败或采样中断超过 30 秒会清零连续计时，不当作恢复。发送结果不明确时记为 unknown，不自动重发；重启保留事件去重状态，但重新累计连续时间。

## 使用黄金观察页

黄金仅保留 USDT 报价永续合约，两侧独立选择交易所和标的，支持同所及跨所配对。默认 A 为 Binance、B 为 Gate，优先匹配同名黄金合约。两腿卡片和跨所组合表中的市场名称可在新标签页打开对应交易所的永续市场。报价总览展示全部交易所黄金永续，可点击设为 A/B。切换方向仅改变买卖侧，不改变 A/B 历史统计口径。当前仍是 REST 行情观察，不执行下单。

主指标是 **当前溢折价减去历史平均溢折价**，以 bps 显示。例：历史平均 -0.5%、当前 -1.2%，偏离为 -70 bps。正值为 A 比历史常态更贵，负值更便宜；原始溢折价仍保留。

历史均值窗口独立选择 24 小时、3 天、7 天或 30 天，默认 7 天。均值基于该窗口内时间戳一致的已收盘小时 K 线，不会因图表周期改变。查询时覆盖率达到 90% 且包含最新已收盘小时线才标记“样本充分”；不足时展示临时均值和覆盖率，基准过期时停止显示实时偏离。均值、最低、最高均由所选窗口的完整小时线计算；切换图表周期或左拖分页不改变统计。页面停留期间保持本次查询的基准快照，重新进入页面可更新。黄金仍不自动报警或交易。

历史图复用海力士页面的图表组件，使用相同的 1m、5m、15m、1H、4H、1D、1W 周期选择，默认 5m；支持滚轮缩放、拖动平移、十字光标、MA5／MA10／MA20 独立开关和“回到最新”。缺失历史分段显示，均线不跨越空窗。

选择 A、B 两腿，或者在报价表点击“设为 A/B”（支持跨所选择）。当前方向价差统一到 USDT／金衡盎司，扩大方向取 `A卖一 / B买一 - 1`，缩小方向取 `A买一 / B卖一 - 1`。切换方向立即重新计算当前价差及其相对历史均值的偏离；历史曲线和均值仍使用固定A/B的收盘价口径。不同黄金合约的指数来源可能不同，不表示可以相互兑换。

- **历史价差概览**：独立基准窗口的均值、覆盖率、样本量，以及同一窗口的小时收盘溢折价最低／最高值，不承诺回归。
- **跨所黄金永续价差组合**：每组展示随盘口轮询更新的当前价差，采用页面上方所选的价差方向；行情过期或两腿采样相差超过 10 秒时显示“—”。历史均值、最低、最高与范围仍按已收盘的同步小时 K 线计算。
- **买卖方向毛价差**：默认折叠，使用两边第一档买卖价，不扣费、不估算大额成交，不包含资金费、滑点及双边保证金成本。
- **外部国际金价未接入**：所选 B 是交易市场，不是独立 XAU/USD 参考。
- 当前不提供黄金异常阈值或黄金通知；先积累实际价差再决定规则。

黄金仅覆盖 USDT 报价的已识别 PAXG、XAUT、XAU 永续，不采集黄金现货。USD、USDC 报价的黄金市场不进入列表或历史比较；因此 Kraken 当前的 USD 黄金永续与 Hyperliquid 的 USD 报价 `xyz:GOLD` 均不进入。Hyperliquid 原生 PAXG 永续虽然使用 USDC 保证金，但报价为 USDT，仍可进入。黄金 ETF、收益型凭证不进入每盎司比较。参见 [Hyperliquid 合约规格](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/contract-specifications)。

黄金实时盘口与历史 K 线均直接使用 USDT 原始报价，不加载或计算 USDT/USD、USDC/USDT 汇率。盘口毛价差仅为观察参考，不是可执行收益。

## 行情采集与覆盖

后端启动后持续执行，无需打开页面或配置交易 API Key。当前用官方 REST 盘口快照，黄金采集每轮结束后间隔 2 秒；稳定币同一盘口请求完成后至少间隔 10 秒，期间保留原采样时间，不把缓存视为新行情；每个交易所产品源最多 3 个并发盘口请求，每个 HTTP 请求 8 秒超时、响应上限 12 MB。目录或源级请求失败从 10 秒指数退避至最多 5 分钟。故障来源与其他来源隔离，禁止同一监控任务重叠执行；关闭服务取消请求并等待在途通知结束。

目录每小时刷新。六家来源为 Gate、Binance、OKX、Bybit、Kraken、Hyperliquid；不包含 Deribit。交易对是否上市以实时目录为准。连接失败、HTTP 403/451、没有适用市场分别展示，不用模拟数据替代。

资产名单在 `apps/backend/src/observation-feed.ts` 版本化维护，不能保证自动发现世界上所有新稳定币。页面“行情覆盖”列出完整名单。Hyperliquid 非 canonical 的 USDe、USDH 使用固定 tokenId 验证，未识别同名币不接入。canonical 不是法币锚定或安全性的认证。

官方参考：[Gate API](https://www.gate.com/docs/developers/apiv4/en/)、[Bybit 市场目录](https://bybit-exchange.github.io/docs/v5/market/instrument)、[Kraken 市场目录](https://docs.kraken.com/api-reference/market-data/get-tradable-asset-pairs)、[Hyperliquid spotMeta](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint/spot)、[USDH HyperCore](https://docs.usdh.com/usdh/hypercore)、[Ethena 集成说明](https://ethena.fi/)。

时效按成功 REST 复核时间判断；不能把盘口最后变更时间当作最后成功复核时间。上游提供当前快照时间时额外校验。超过 30 秒未复核的报价不参与信号或历史；黄金两腿与汇率的采样时间差不得超过 10 秒。

## 历史与接口

参考海力士的方式：向交易所查询原始 K 线，按相同时间戳对齐后计算溢折价。复用 SQLite 的 `candle_cache` 表，使用 `OBSERVATION:` 市场命名空间，避免混入交易页缓存；不另外保存计算后的溢折价。普通周期每市场最多缓存 500 根，小时周期最多 1000 根，以支持 30 天均值。旧版 `observation_history` 表保留兼容，正式行情源不再写入分钟采样。

进入黄金页时查询一次；切换市场、图表周期或均值窗口按需查询，同次访问切回已加载的组合直接复用页面缓存。页面不提供单独的历史刷新按钮。后端合并相同在途请求，并保留 30 秒请求缓存；上游失败时允许展示已有 K 线，但明确提示历史查询失败。

仅使用 USDT 报价市场的已收盘 K 线，按相同时间戳直接比较两腿原始收盘价，不请求历史汇率 K 线。K 线收盘价与当前盘口中间价的采样口径不同，历史均值用于观察参考。周线由日线按 UTC 周一分桶取最后收盘价。

图表首次请求约300根（周线取500根日线聚合），默认展示最近约120个周期，周线默认展示52周。左侧剩余不足30根时，按 `before` 游标加载更早一页；按时间合并去重并保持可视范围，不回到最新端。更早数据仅保留在当前浏览器访问缓存，不挤占数据库近期K线缓存，也不重新计算本次均值。加载失败可继续拖动重试；接口无更早数据时显示边界提示。历史不定时刷新，实际覆盖取决于上市时间和交易所接口限制。黄金不再使用 Kraken USD 永续或其现货汇率；稳定币数据源仍可使用 Kraken 现货。历史不足保留缺口，不伪造或外推。稳定币事件仍保留 90 天。

| 接口 | 功能 |
| --- | --- |
| `GET /api/asset-monitor` | 当前稳定币方向、黄金报价、设置、覆盖与最近事件 |
| `PUT /api/asset-monitor/settings` | 保存稳定币提醒设置，需要 `x-gct-monitor-intent: update-settings` |
| `GET /api/asset-monitor/history?a=市场ID&b=市场ID&hours=10&referenceHours=168&intervalMinutes=5` | 黄金两腿历史；hours 允许 1–12000 的整数（单页时间跨度）；before 为可选毫秒游标，返回 nextBefore/hasMore；intervalMinutes 允许 1、5、15、60、240、1440、10080（默认 5）；referenceHours 允许 24、72、168、720，默认 168；fresh=1 强制刷新 |

接口遵循现有 Host/Origin 限制；金额以十进制字符串传输，后台计算使用 Decimal。页面每次读取完成后间隔 1 秒读取当前行情快照；历史无定时轮询，由进入或切换触发。连接失败立即停止实时判断。

## 验证与复现

在项目根目录执行：

```bash
npm run build
npm run test -w apps/backend -- src/asset-monitor.test.ts src/observation-candles.test.ts src/app.test.ts src/database.test.ts
npm run test -w apps/frontend -- src/frontend-routes.test.ts
npx playwright test e2e/asset-monitor.spec.ts
```

固定响应测试涵盖六家现货目录、盘口解析、反向价格与容量、严格阈值、汇率缺失、过期、持续计时、重启去重及历史保留。浏览器测试覆盖独立路由、稳定币列表、设置、黄金同所配对、独立历史均值与窄屏。

2026-09-23 改为仅监控 USDT 黄金之前的本机连通性检查：Gate、OKX、Kraken 与 Hyperliquid 返回有效黄金盘口；其中 Kraken 的黄金盘口为 USD 报价，当前已排除。Hyperliquid 返回 USDe/USDC、USDH/USDC 现货盘口；Binance 返回 HTTP 451，Bybit 返回 HTTP 403。此记录仅代表该次网络环境，不是部署环境可用性保证。

### Binance 现货目录响应过大

`response_too_large` 是本地 12 MB 响应保护，不表示交易所断网。2026-09-23 实测未筛选的 `exchangeInfo` 返回 HTTP 200、17,620,265 字节；增加 `permissions=SPOT&showPermissionSets=false&symbolStatus=TRADING` 后降为 2,486,671 字节。现货采集已采用这一精简请求，仍保留响应上限。字段说明见 [Binance 官方 exchangeInfo 文档](https://github.com/binance/binance-spot-api-docs/blob/master/rest-api.md#exchange-information)。回归测试覆盖冗余权限数据导致的超限与精简后正常发现市场。

### 交易所历史回填验证

2026-09-23 改动前本机使用实时市场目录验证：Gate 黄金永续与现货配对、OKX `XAU-USDT-SWAP` 与黄金现货配对，均返回 120 个 5 分钟同步图表点，以及完整 720 个小时同步样本（30 天均值）。冷查询分别约 0.5 秒、1.6 秒。另已取得 Binance 现货／永续、Kraken 现货／永续、Bybit 永续、Hyperliquid PAXG 与 xyz:GOLD 的有效小时 K 线；Kraken 黄金与 xyz:GOLD 现已因 USD 报价被排除。该结果是一次连通性记录，不保证所有市场及历史窗口均有数据；已退市或无近期成交的市场不能因为接口返回 HTTP 200 就判为历史充分。
